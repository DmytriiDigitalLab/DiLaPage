# Сайт DiLa (лендинг)

Статический одностраничный сайт на польском: HTML, CSS и JS без сборки и зависимостей. Шрифты лежат вместе с сайтом, поэтому IP посетителей не передаётся Google (важно для RODO).

## Как посмотреть
Откройте `index.html` двойным кликом. Для проверки формы удобнее локальный сервер:
```
cd site
python -m http.server 8000   # затем http://localhost:8000
```

## Структура
```
site/
├── index.html                 ← вся страница
├── polityka-prywatnosci.html  ← политика конфиденциальности (черновик)
├── assets/css/style.css       ← дизайн-система и стили
├── assets/js/main.js          ← CONFIG (контакты), демо-анимация, калькулятор, форма
├── assets/fonts/              ← Fraunces, Inter, JetBrains Mono (woff2, variable)
└── assets/img/favicon.svg
```

## Форма
Сейчас форма собирает письмо и открывает почтовую программу посетителя: без сервера и без хранения данных. Чтобы получать заявки напрямую, подключите Formspree, Netlify Forms или Web3Forms: это замена обработчика `submit` в main.js. После этого обновите пункт 3 политики.

## Публикация (бесплатно)
- **Cloudflare Pages** или **Netlify:** перетащить папку `site` в панель, подключить домен.
- **GitHub Pages:** репозиторий, затем Settings → Pages.
- Домен `.pl` (~50–100 zł в год) + почта на домене (Zoho Mail free, Google Workspace, или у регистратора).

## Решения по дизайну
- **Направление:** «лаборатория для бизнеса» — тёплая бумага `#f7f5f0`, тёмные чернила `#0f1720`, один сигнальный цвет (киноварь `#ea5a2f`), моно-подписи в стиле протокола («01 — PROBLEM»), сетка миллиметровки в тёмных секциях.
- **Шрифты:** Fraunces (заголовки, редакционный serif — выделяет на фоне типичных SaaS-сайтов), Inter (текст), JetBrains Mono (данные, цифры, подписи).
- **Продающая логика:** боль (таймлайн одного запроса, конкурент отвечает первым) → цифры клиента (калькулятор) → решение (4 шага + человек) → снятие страхов (6 принципов, FAQ) → расширение (модули) → процесс → цены → пилотная программа (честный дефицит: 3 места) → автор → контакт.
- **Без выдумок:** нет фальшивых отзывов, логотипов клиентов и статистики. Цифры либо из калькулятора (вводит сам посетитель), либо помечены как пример или допущение. Когда появятся реальные кейсы, добавить секцию «Wyniki» между «Rozwiązanie» и «Zasady».
- **Доступность:** контраст AA, фокус с клавиатуры, `prefers-reduced-motion`, семантические заголовки, страница работает без JS.
